# Documentación

Este directorio guarda el contexto estable del proyecto, sus convenciones y las decisiones relevantes. No es un backlog ni una descripción detallada del código.

## Fuentes de verdad

| Tema                                                    | Fuente de verdad |
| ------------------------------------------------------- | ---------------- |
| Backlog, historias, sprint, responsables y estado       | Trello           |
| Comportamiento técnico, estructura y configuración real | GitHub / código  |
| Contexto estable, convenciones y decisiones             | Esta carpeta     |

Si un documento contradice al código, el código manda y el documento debe corregirse.

## Índice

- [Contexto de negocio](product/contexto-negocio.md): qué problema resuelve el producto.
- [Primeros pasos](development/getting-started.md): requisitos, instalación y scripts actuales.
- [Convenciones](development/conventions.md): Git, Pull Requests y criterios de desarrollo.
- [Baseline de seguridad](security/security-baseline.md): reglas mínimas y decisiones pendientes.
- [Decisiones de arquitectura (ADR)](adr/README.md): qué son, cuándo escribirlas e índice.
